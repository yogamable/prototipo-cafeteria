# Prototipo de Sitio Web para Cafetería

![Vista previa del sitio](docs/preview.png)

## Descripción del proyecto

Diseño y desarrollo de un prototipo de sitio web para una cafetería, orientado a presentar sus productos y su propuesta visual en una experiencia de una sola página, agradable de recorrer y fácil de usar.

El proyecto utiliza HTML, CSS/SCSS y JavaScript, e incorpora composiciones fotográficas con filtros y capas, un carousel dinámico y un sistema de contacto por correo.

> **Importante:** este prototipo está diseñado únicamente para visualización en pantalla completa (escritorio). No cuenta con versión adaptada para tablets ni dispositivos móviles.

## Funcionalidades

* **Sitio de una sola página:** todas las secciones se encuentran en un único documento, con navegación fluida entre ellas.
* **Menú de navegación:** enlaces en el encabezado que llevan directamente a cada sección de la página.
* **Carousel con JavaScript:** muestra tres tarjetas a la vez y avanza de a una mediante flechas. Funciona de forma circular: al llegar a la última tarjeta, vuelve a la primera.
* **Composiciones fotográficas:** combinación de imágenes con filtros CSS y posicionamiento en el espacio para crear profundidad visual.
* **Diseño agradable e intuitivo:** interfaz pensada para que el usuario encuentre la información de forma simple y rápida.
* **Correo de contacto:** el sitio incluye la integración de correo, actualmente deshabilitada en este prototipo. Puede habilitarse fácilmente configurando un servidor con PHP y los datos del correo de la cafetería.

## Tecnologías utilizadas

* HTML5
* CSS3
* SCSS
* JavaScript (ES6+)

## Objetivo

Desarrollar un prototipo de sitio web atractivo y funcional, aplicando conceptos de desarrollo FrontEnd como maquetación con SCSS, composición visual con filtros y capas, navegación por secciones y manipulación del DOM con JavaScript para la creación de un carousel circular.
